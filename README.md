# React Shop

React 기반 쇼핑몰 포트폴리오입니다.  
상품 목록, 상세 페이지, 장바구니, 찜하기, 최근 본 상품, 검색/필터/정렬, 다크모드를 구현했습니다.

# What I Focused On

이 프로젝트는 단순한 정적 쇼핑몰이 아니라,
실제 프론트엔드 실무에서 사용하는 React 구조를 학습하고 적용하는 데 집중했습니다.

특히 다음 부분에 초점을 두었습니다.

- 컴포넌트 분리
- API 기반 데이터 처리
- 서버 상태 관리
- 전역 상태 관리
- 유지보수 가능한 폴더 구조
- 사용자 경험 중심 UI 개선
